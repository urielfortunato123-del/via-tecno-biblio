## Módulo Biblioteca Técnica Offline

Desenvolva um módulo totalmente novo integrado ao sistema existente de Fiscalização Rodoviária.

NÃO altere nenhuma funcionalidade existente.

Apenas adicione um novo módulo profissional chamado:

📚 Biblioteca Técnica

Este módulo será um centro de conhecimento técnico offline para fiscais, engenheiros, gestores e equipes de conservação rodoviária.

########################################################

OBJETIVO

########################################################

Criar um sistema semelhante ao Google, porém utilizando SOMENTE documentos oficiais cadastrados.

O sistema deve responder perguntas técnicas mesmo sem internet.

Ele deverá funcionar totalmente OFFLINE.

Nunca utilizar respostas inventadas.

Toda resposta deverá obrigatoriamente indicar:

• Documento

• Órgão

• Ano

• Capítulo

• Item

• Página

• Trecho original utilizado

Caso a informação não exista nos documentos cadastrados, informar:

"Informação não encontrada na biblioteca técnica."

Jamais criar respostas por IA sem fonte.
